# Rachita Constructions — React website starter

An editorial-luxury, responsive React + Vite website concept for Rachita Constructions.

## Run locally
1. Install Node.js (LTS).
2. Extract this ZIP.
3. Open a terminal in the extracted `rachita-constructions` folder.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL printed by Vite (usually `http://localhost:5173`).

## What's included
- Responsive homepage and mobile navigation
- Project cards with working category filters
- Company story, approach, services and enquiry sections
- Enquiry form interaction (demo-only; it does not send data)
- React component source and CSS
- Basic page metadata

## Before publishing
- Replace illustrative Unsplash imagery with Rachita-owned, approved project photography.
- Confirm current project statuses, locations, and availability with Rachita.
- Connect the enquiry form to an approved email/CRM/backend endpoint.
- Confirm contact information, privacy/consent language, and legal/RERA details where applicable.
- Add analytics, production SEO metadata, accessibility QA, and deployment configuration.

## Note
This is a front-end concept, not a deployed or production-connected website. External Google Fonts and Unsplash images require internet access.
